# Code of conduct

Be straight with people and assume they are trying. Concretely:

- Critique the change, not the person. "This drops the file when the peer is
  mid-restart" is useful; "this is sloppy" is not.
- No harassment, no personal attacks, no bigotry. Anyone who needs that
  explained is not welcome in the issue tracker.
- Assume the other person has less context than you, because they do.

Report a problem to the maintainer privately (open an issue marked as such, or
email the address in `Cargo.toml`'s repository owner profile on GitHub). Reports
are read by the maintainer only, and a first response is not a promise of a
particular outcome.

The long version of this text is the [Contributor
Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/);
where it and this page disagree, this page wins, because it is shorter.
